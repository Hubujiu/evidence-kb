01 / 一次知识问答如何流转

默认产品链路
01 · 请求

用户与 API

身份认证、会话创建、问题与约束输入

02 · 插件编排

Rust loop → kb_query

Profile 装配服务；原生 single-tool loop 调用绑定当前身份与会话的知识库工具

03 · 检索

授权检索与重排

按权限召回、融合候选，定位原文证据

04 · 生成

上下文与回答

装配证据、裁剪上下文、生成并按需核验修复

05 · 交付

答案与引用

再次校验权限与证据，返回答案、引用和状态

知识库工具内部：规划 → 工具（可循环）→ 生成 → 核验 / 修复 → 交付；业务策略由 KnowledgeWorkflow 维护。外层 Rust loop 直接交付已核验结果，不增加模型请求，也不自动重发未决效果。

02 / 功能模块

按职责查看
接入

交付配置与 API

加载运行配置、初始化身份和预算；提供知识库、文档、检索、引用及会话接口。

内容

文档入库与解析

上传和绑定文档；解析 PDF、Office、Markdown 等，形成可追溯的原文快照与证据单元。

检索

索引、召回与证据

默认使用 PostgreSQL 的关键词与向量检索；候选融合、重排、原文读取和权限复核。

内核

Rust 插件宿主与 loop

检查依赖、作用域与服务所有权，控制准入与卸载；loop 发出会话、上下文、模型和工具效果，由 Python 服务执行。

装配

Profile 与可替换服务

从可信 catalog 选择模型、工具、上下文、会话和 loop 实现；通过声明的依赖注入，资源按作用域登记与清理。

业务

知识库与持久会话

RAG 作为 kb_query 工具接入；KnowledgeService 保留规划、证据核验与交付。AgentStore 维护 revision、事件、租约与历史。

控制

模型调用与预算

提供者适配、实际请求采集、调用预算预留、失败与未知状态记录。

验收

统一 RAG 评测

版本化用例、执行与评分，支持精确缓存、历史回放及离线合同检查。

03 / 状态与数据存放

默认路径与条件性组件
PostgreSQL默认检索索引、检索代际、语义页活动清单与 Embedding 恢复任务。
SQLite · 会话会话状态、事件、请求租约和结果；交付目录 sessions/sessions.sqlite3。
SQLite · 账本 / 缓存物理请求预算账本；外部 PDF 页面解析满足授权条件时使用页面缓存索引。
文件与历史后端原件、解析缓存对象、运行记录与报告；embedded 检索仅在明确配置时使用 SQLite 索引。

原件文件用于备份下载；证据以数据库中的不可变解析快照为准。评测目录也可能产生独立的 SQLite 账本与缓存。原生句柄与通用内存会话只属于当前进程和运行，不替代 AgentStore 或提供跨进程恢复。

04 / 横向保障

权限与证据

检索、历史复用、模型调用前及交付环节进行授权或证据复核。

请求与恢复

请求指纹、单写者租约和物理请求账本防止未决调用被盲目重发。

架构与质量

统一检查入口运行依赖方向检查、离线合同和评分控制样本；不代表线上 RAG 质量验收。

05 / 核心函数说明

逐项核对的业务语义
会话

AgentStore.begin

输入：用户身份、会话 ID、请求 ID、预期 revision、请求指纹和租约时长。
对象：SQLite 会话与请求记录。
处理：核验归属、幂等请求、版本与活跃写入；创建租约，或返回已完成结果。
输出：缓存结果，或租约 token 与会话快照；冲突时抛出平台错误。

会话

AgentStore.finish

输入：用户身份、会话 ID、租约 token、新状态与响应。
对象：会话、请求和事件记录。
处理：验证归属与租约，在同一事务中记录完成事件、更新状态及 revision、保存响应。
输出：附带会话 ID 和新 revision 的响应。

编排

Runtime.run

输入：提供 next / execute / accept 的程序、操作上限、截止时间与取消信号。
对象：Rust 生命周期状态与 Python 效果执行。
处理：逐项取出指令，经原生准入执行并关联结果；在效果前后检查取消和期限。
输出：程序的 Complete 值；异常向调用方传播，不自动重试效果。

工具

NativeLoop.invoke

输入：可信调用者绑定的工具、身份上下文、参数及运行限制。
对象：single-tool 原生 loop 和注入的工具、会话服务。
处理：持有宿主租约，按原生指令记录会话与执行工具；不调用外层模型。
输出：工具结果；结束时关闭原生 loop 句柄。

生命周期

PluginHost.close

输入：当前插件宿主。
对象：宿主树、运行租约和插件登记的资源。
处理：停止新准入，检查在途调用，关闭子作用域并反向清理；失败保留未释放资源以便重试关闭。
输出：成功后宿主关闭；忙碌或清理失败时抛出异常。

工作状态

begin_work_state

输入：上一工作状态、当前问题、约束和来源 epoch。
对象：单会话工作状态。
处理：仅当 epoch 一致时复用目标和近期证据，创建新一轮规划状态。
输出：包含目标、当前请求、约束、证据 ID 等字段的新字典。

预算

BudgetLedger.reserve

输入：物理请求 ID、各预算维度的预留量、类别和是否要求所有请求已结算。
对象：SQLite 物理请求账本。
处理：在写事务内核对预算、未决请求和重复 ID，登记 STARTED 请求。
输出：获准的请求 ID；条件不满足时抛出异常。

缓存

StageCache.get

输入：精确阶段键、当前授权回调、运行模式和是否为被测阶段。
对象：SQLite 缓存索引与内容寻址 JSON。
处理：重新验证权限；按模式决定是否绕过；命中时检查对象哈希。
输出：通过校验的缓存内容或 None；授权及完整性失败时抛出异常。
