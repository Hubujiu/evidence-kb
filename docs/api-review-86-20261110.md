## 形式化映射审查

ParseAdmission 继续描述存储原件、解析、当前权限与修订复核、元数据提交及 READY 构建准入。Platform.ingest 的锁、复核、事务和不可变校验不变，修改的是解析记录中的处理配置。AtomicAuthorityCommit 的锁持有和提交确认转换不变。PageCache、PageFallback 的部分结果、来源身份和独立页面恢复转换不变，_Bundle 的处理格式身份需更新审查绑定。

本轮只刷新 ingestion_migration、knowledge_atomic_commit 的 Platform.ingest，以及 page_recovery 的 _Bundle 三个已确认漂移锚点。新增 processing_flags 的依赖锚点，并把 _catalog 纳入 authority_publication 的审查盘点。模型、不变量、负控、界限和门槛保持原样。

AuthorityPublication 抽象权限修订、构建和发布，不模拟具体解析文档或管线目录连接。ParseAdmission 抽象原文身份，不证明解析 JSON 序列化或快照哈希构造。本轮真实组件与 HTTP 反例承担这些未覆盖义务。追加源码摘要是审查绑定，不是实现精化证明。
